## Overview

The z_archive directory contains my non-Guru Frontend Mentor solutions, ranging from Newbie to Advanced difficulty, completed throughout the early stages of my web development journey. It serves as a record of my progression and a reminder of how far my skills have developed.

These projects represent my first experiences with many core concepts, from fundamental HTML and CSS techniques to building React applications with JavaScript and React Hooks. They were completed before I had developed the engineering practices, tooling, and coding standards that I now apply across my projects.

The code has been preserved largely as originally submitted to maintain an authentic record of my learning. For consistency and readability, I have applied basic formatting with Prettier and addressed straightforward ESLint and Stylelint issues where possible. In a few cases, ESLint rules have been disabled inline rather than significantly refactoring the original solutions, preserving them as an accurate reflection of my understanding at the time.
